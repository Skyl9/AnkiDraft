AnkiDraft vous aide à transformer rapidement un chapitre dense en flashcards atomiques, tout en vous laissant le dernier mot sur chaque carte grâce à la revue humaine.

## 1. Deux ateliers complémentaires : Studio de Création vs Batch Factory

AnkiDraft sépare clairement la création **ciblée** (un extrait, une saisie libre) de la production **par lots** (tout un livre découpé en tâches) :

### Option A — Studio de Création (<kbd>Alt+2</kbd>) : ciblé & interactif
Idéal pour travailler sur **un passage précis**, **une section** ou **une Nouvelle Saisie Libre** (<kbd>Ctrl+N</kbd>) :
1. Ouvrez **Studio de Création** (<kbd>Alt+2</kbd>).
2. Dans l'explorateur à gauche, sélectionnez un document/chapitre ou cliquez sur **Nouvelle Saisie Libre** (<kbd>Ctrl+N</kbd>).
3. Choisissez le modèle de carte (*Basique*, *Texte à trous / Cloze*), le paquet de destination et le moteur IA, puis appuyez sur <kbd>Ctrl+Entrée</kbd>.
4. Relisez chaque carte une par une avec son aperçu en direct (<kbd>Espace</kbd> pour valider, <kbd>Suppr</kbd> pour rejeter), puis enregistrez (<kbd>Ctrl+S</kbd>).

### Option B — Batch Factory (<kbd>Alt+6</kbd>) : usine de production par lots
Idéal pour traiter **plusieurs chapitres ou plusieurs documents** en file d'attente :
1. Ouvrez **Batch Factory** (<kbd>Alt+6</kbd>).
2. Cliquez sur **Composer le lot…** (<kbd>Ctrl+N</kbd>) pour découper vos documents ([Cibler les chapitres](/fr/sources/scope-and-slices/)) :
   - **Mode Direct** : chaque section cochée produit une tâche dédiée.
   - **Mode Automatique** : regroupe ou découpe les sections selon leur longueur.
3. Choisissez le type de carte, le paquet Anki cible et lancez la file (<kbd>Ctrl+Entrée</kbd>). En cas d'incident sur une tranche, utilisez **Reprendre le lot** sans tout relancer.
4. Validez l'ensemble des cartes produites dans le panneau **Staging** avant enregistrement.

## 2. Personnaliser le style des cartes (Personas)

Vous pouvez adapter le ton et l'exigence de l'IA selon votre domaine d'étude :
- **Sciences & Médecine** : définitions précises, mécanismes physiopathologiques, valeurs de référence.
- **Droit & Sciences humaines** : notions clés, distinctions conceptuelles, dates et arrêts.
- **Langues & Vocabulaire** : exemples contextualisés, expressions idiomatiques et prononciation.

## 3. Revue humaine avant enregistrement (Staging)

Aucune carte générée par l'IA n'est ajoutée aveuglément à votre collection : toutes les propositions arrivent dans la file de **Revue (Staging)** où vous pouvez les accepter, les modifier ou les rejeter en un clic.
